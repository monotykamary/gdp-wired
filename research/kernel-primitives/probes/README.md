# Native primitive differential probes

Run **only on the supercomputer boat** for development (parent owns submissions); the isolated CI workflow runs on Ubuntu 24.04. Entry point: `bun research/kernel-primitives/probes/run.ts`. Needs Bun (TypeScript), C compiler supporting `__int128` (GCC/Clang), Rust `rustc`, Go, and Python 3; no packages beyond the repository. The runner compiles in a temporary directory, deletes it, and emits one bounded JSON receipt (`caseCount`, per-language mismatch counts, at most 12 mismatch examples/language) with nonzero exit on any malformed/missing receipt, compilation/process failure, timeout, or semantic mismatch. No native failure is skipped. Inputs and successful outputs cross process boundaries as exact decimal strings; `Number` is used only for boolean signedness and width.

Widths 8/16/32/64; both signednesses; WRAP/SATURATE/TRAP; add/sub/mul/neg/cast/div/rem; FLOOR/TRUNCATING/EUCLIDEAN. Cases include complete boundary/sign cross-products, zero divisors, signed MIN/-1 division **and remainder** pair trap, seeded values, and casts around and far beyond 64-bit limits (up to 101 bits, safely inside the C/Rust 128-bit transport). Non-cast inputs are always within target bounds. Native failures compare as failure, not spelling of diagnostic reason; diagnostic reasons appear in samples. Comparisons of successful values are exact strings.

Coverage honesty:
- **C:** native unsigned `uint64_t` wrapping arithmetic reduced to width, native truncating division on `__int128`; checked bounds and signed overflow use `__int128` adapters, never execute C signed-overflow UB. The full unsigned 64-bit product uses unsigned `__int128` to avoid signed overflow.
- **Rust:** native width-specific checked/wrapping/saturating arithmetic for all four arithmetic operations; division modes, MIN/-1 pair policy and casts use explicit 128-bit adapters.
- **Go:** native `uint64` unsigned WRAP arithmetic; narrower-width reduction, signed behavior, SATURATE/TRAP, division modes, and remainder pair policy are explicit `math/big` adapters. Go `big.Int.QuoRem` provides native truncation over arbitrary precision, **not** a fixed-width machine primitive.
- **Python:** arbitrary-precision `int` arithmetic and native FLOOR `//`/`%`; all fixed-width reduction, overflow and division-pair trap policies are explicit adapters, **not native fixed-width primitive coverage**.

The protocol covers cast operands only up to 101 bits for C/Rust's `__int128` transport; the imported kernel itself accepts arbitrary-precision BigInt, which is outside this native probe's cast transport range. No generated mirror of the TypeScript kernel is used as a stand-in for a native toolchain: each source runs in its corresponding toolchain and produces the independent result.

# Cut-context and bounded-decline successor — source notes

Implementation is untested until the separately authorized, single boat gate. A source review is not a native proof or diagnosis of qacw8q.

## Transport boundary

`replayCountCertificate` receives actual source/target counts and retains the certificate's original frame/mono/linear arrays. Main mapping, checking and collection use native framePath ordering on the original branch path. Independent lemma proofs retain only their negated cut and guards. Every emitted complete proof still reaches the unchanged native checkMC. Invalid or unavailable count contexts refuse.

All three production `transportCountCertificate` callers now supply their actual source/target obligation declarations; the public wrapper derives counts from the original reads **only for nonlemma-cut certificates**. Cut-free and lemma-only callers retain the old route. Scoped replay retains original declaration references and derives counts on demand. **Reference retention does not mean zero eager hashing/accounting cost:** declarations are traversed by the existing metered receiptStamp whenever a checked-reduced receipt is minted or verified. No timing, counted-cost, memory/OOM-avoidance, or universal flags-off identity claim follows from this change.

## Observation and bounds

The dedicated callback is observational and does not run search, renew an allowance, install the full timed trace, or change the single persistent repair bit. A resolver result labels both its returned payload premises and the controller's effective union with prior premises. The exported supplier delta is derived from that effective union. A start without a result is not a completed repair.

The serializer bounds bytes, depth, string prefixes, and **every visited value/property iteration**, including skipped undefined/inherited/omitted properties. It never calls ordinary property getters. Its bound concerns explicit traversal/encoding, not VM-internal enumeration allocation, heap/RSS, or adversarial Proxy traps. Prefix hashes are labelled prefix-only; incomplete data is never labelled replayable.

Identity and member summaries are separately byte/work bounded, not just event/history rings. Only complete member names up to 256 characters can join; longer names get an unavailable identity rather than a colliding prefix join. Whole-artifact validation uses the actual io.encode implementation with the 2 MiB cap, including the trailing newline. If all bounded sections together exceed the cap, all optional event/history/summary sections are dropped, counters and unknown status are updated, and the bounded identity/header remains. The driver enforces the same cap in save.

Diagnostic capture, serialization, finalization and save are included in the reported observed wall interval but are **not charged as proof units**. This is deliberately not timing-neutral. The ordinary full trace remains instrumented-mode only. Receipt binding requires the native-exported artifact, complete source/packet identity, and hashes of the sealed input index and seal.

## Protected behavior

The kernel is unchanged. Hard-stop identity, the existing capacity-refusal boundary, original instances, lazy supplier capture, complete generalized supplier reconstruction, prior effective premises, all-held reclosure and the single persistent recovery bit remain. No extra native admission, retry, resource change or replacement claim is authorized. Existing historical receipts and the global-OOM chronology remain unchanged.

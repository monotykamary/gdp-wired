## Order of subsequent batches

1. Prioritize sites that actually flaked: cube, the Java fixtures, and any later strict-gate failure.
2. Authenticate the current source/API and inherited owner. A relocated or unresolved call stays unresolved; an empty AST grant list is not proof of a watchdog.
3. Measure completed work on the original claims, including positive, broken/refusal and cancellation controls. A wall duration is never converted arithmetically into a work grant.
4. Preserve the original mathematical and source contracts. Document unsupported source semantics rather than manufacturing observations or dropping positive coverage.
5. Run cheap types/lint/targeted controls first. Then admit the required native checks with source/runtime/placement/custody and cleanup receipts.
6. Publish stable row IDs, source revision, measured units, chosen margin, original watchdogs, verdicts and precise evidence for each accepted batch. Leave every unconverted row visible and update the integrated manifest without rewriting the historical baseline.

A real process watchdog remains an interruption ceiling, not a semantic allowance. Budget ownership, min-parent clamping and explicit refusal remain authoritative. Completed honest source refusal is preserved; a generic unfinished unknown is not relabeled as a completed proof or source result.

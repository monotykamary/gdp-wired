`*.json.gz.model.gz` contains a measured model and regression expectations, generated by **our solver only**, not an external solver. Boat evidence: `runs/counts-audit-1`; missing mldr 1/4/5 models retried with Q3's newer untrusted solver in `runs/counts-audit-2`. The residual and four earlier hand models are Q3's original supplied witnesses, validated against their goals. Additional evidence: `runs/counts-hand-audit` and `runs/counts-complete`. Hand-5/6/7/9 duplicate the exact hypotheses of hand-1/2/3/4 and are not counted twice. Each test independently checks the model against the frozen hypotheses before examining count inconsistencies. These are abstract models, not reachable protocol traces.

The 9 original fixtures include four hand goals: one value decided, decision has votes, choosable, busy rows. Some other dumps say only `goal: counted`; do not invent law names. Later Paxos 1 is the Decision/member bound; 2/3 are Proposal/choosable bounds. The current Q3 NEXT.md belongs to a subsequent timing lane, so its completion claims are not evidence for these snapshots.

`q3b-capture-7` is a flattened read-model goal containing `gdpModel…` variables **without their read definitions**. It can be model-checked as dumped but cannot be faithfully reconstructed as concrete map counts. The recovery helper returns no counts and the test records that limitation. A count-consistent model of hand-3 (choosable) also survives. Neither is silently counted as an eliminated spurious model.

Recovery of `Count` from expanded `countHyp` clauses is test/audit support only. Production callers must use declarations and `countsForReads`, never this recovery. No recovered declaration is admitted by a checker.
